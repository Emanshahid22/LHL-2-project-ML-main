## User Story
As a defence solicitor, I want to know why a field the case should have filled is empty, so that I can tell "the case does not say" from "the machine did not try".

## Acceptance Criteria
- Given a mapped field the case cannot supply, when population runs, then it is left blank and carries a note explaining why.
  - Covered by: e2e/uc02-autofill.spec.ts › `missing case data is flagged with a no-data note`
- Given a field with no mapping at all, when the form renders, then it carries no auto-fill note — it was never a candidate.
  - Covered by: e2e/uc02-autofill.spec.ts › `unmapped fields carry no auto-fill note`
- Given a mapped field left blank, when I type into it, then the note disappears, because it no longer describes the field.
  - Covered by: e2e/uc02-autofill.spec.ts › `auto-fill leaves fields the case cannot supply blank`
- Given every non-fill outcome, when the API responds, then each carries a human-readable reason rather than a bare status.
  - Covered by: e2e/uc02-autofill.spec.ts › `ambiguous and no_data outcomes are reported with reasons`

## Notes & Constraints

- **Deviation from the scope**, recorded in `open-questions.md` D1: the scope says non-mappable fields are
  "flagged as 'Requires manual entry'". As built, only *mapped* fields that could not be filled carry a
  note. An unmapped field carries nothing, because required marking already says it needs completing and
  a note on every unmapped field would put a badge beside 51 of MG3's 59 boxes.

- Resolver: `libs/shared/src/lib/autofill.ts` (pure). Service: `apps/api/src/drafts/drafts.service.ts`.
  Badges and notes: `apps/web/src/app/shared/dynamic-form/dynamic-form.ts`.
- **`mapsTo` only where the case datum genuinely IS the field.** An MG11 witness is not the defendant;
  MG16 `subjectName` stays unmapped pending a legal ruling. Never map signatures or non-OIC officers.
- Provenance matching is a `JSON.stringify` comparison, so dates must stay ISO strings in controls —
  `provideNativeDateAdapter` would silently kill every badge (CLAUDE.md rule 7).
- **Additive only:** a field id is permanent; `valuesJson` and `autoFillJson` are both keyed by id.
