## User Story
As a defence solicitor, I want a case-linked form to arrive already filled where the case can fill it, so that I start from the case file rather than from a blank page.

## Acceptance Criteria
- Given a new case-linked draft with a mapped template, when I open it for the first time, then the mapped fields the case can supply are already filled.
  - Covered by: e2e/uc02-autofill.spec.ts › `first open of a case-linked draft populates and summarises`
- Given the same draft, when the population runs, then it writes only the mapped fields — no unmapped field is given a value.
  - Covered by: e2e/mg4-charge-sheet.spec.ts › `auto-fill populates exactly the mapped fields and nothing else`
- Given a draft that already holds values, when I open it again, then population does not run again automatically.
  - Covered by: e2e/uc02-autofill.spec.ts › `population never overwrites a manual value on re-run`
- Given an auto-filled date field, when it renders, then it shows DD/MM/YYYY while storing the ISO string.
  - Covered by: e2e/uk-dates.spec.ts › `an auto-filled date shows UK format and keeps its badge`

## Notes & Constraints

- The first-open trigger requires all four of: a `caseId`, at least one mapped field, no existing
  provenance, and no complete value. Any one failing means the draft is not new and nothing runs.
- Population is one case read plus one draft write regardless of how many fields are mapped.

- Resolver: `libs/shared/src/lib/autofill.ts` (pure). Service: `apps/api/src/drafts/drafts.service.ts`.
  Badges and notes: `apps/web/src/app/shared/dynamic-form/dynamic-form.ts`.
- **`mapsTo` only where the case datum genuinely IS the field.** An MG11 witness is not the defendant;
  MG16 `subjectName` stays unmapped pending a legal ruling. Never map signatures or non-OIC officers.
- Provenance matching is a `JSON.stringify` comparison, so dates must stay ISO strings in controls —
  `provideNativeDateAdapter` would silently kill every badge (CLAUDE.md rule 7).
- **Additive only:** a field id is permanent; `valuesJson` and `autoFillJson` are both keyed by id.
