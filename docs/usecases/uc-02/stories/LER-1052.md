## User Story
As a defence solicitor, I want to re-run auto-fill on demand, so that a case updated after I started the form can still fill the boxes I have not touched.

## Acceptance Criteria
- Given the case-changed banner, when I press Re-run auto-fill, then population runs again and reports what it changed.
  - Covered by: e2e/uc02-autofill.spec.ts › `a case that changed after population surfaces the banner, and Re-run clears it`
- Given a re-run, when it writes, then fields I edited by hand are skipped and fields I cleared are refilled.
  - Covered by: e2e/uc02-autofill.spec.ts › `population never overwrites a manual value on re-run`
  - Covered by: e2e/uc02-autofill.spec.ts › `re-run refills a field that was cleared back to empty`
- Given a re-run, when it completes, then only the fields it actually wrote are patched into the open form, so unsaved typing elsewhere survives.
  - Covered by: e2e/uc02-autofill.spec.ts › `a case that changed after population surfaces the banner, and Re-run clears it`
- Given the scope's DoD phrase "works without losing manually entered values", when the suite runs, then a check proves it.
  - Covered by: e2e/uc02-autofill.spec.ts › `population never overwrites a manual value on re-run`

## Notes & Constraints

- The re-run patches **only the fields this run wrote** (`result.values`), not the whole form, so
  anything typed since the last save is not clobbered by the response.
- A re-run also reports its own summary and a snackbar naming how many fields it updated.

- Resolver: `libs/shared/src/lib/autofill.ts` (pure). Service: `apps/api/src/drafts/drafts.service.ts`.
  Badges and notes: `apps/web/src/app/shared/dynamic-form/dynamic-form.ts`.
- **`mapsTo` only where the case datum genuinely IS the field.** An MG11 witness is not the defendant;
  MG16 `subjectName` stays unmapped pending a legal ruling. Never map signatures or non-OIC officers.
- Provenance matching is a `JSON.stringify` comparison, so dates must stay ISO strings in controls —
  `provideNativeDateAdapter` would silently kill every badge (CLAUDE.md rule 7).
- **Additive only:** a field id is permanent; `valuesJson` and `autoFillJson` are both keyed by id.
