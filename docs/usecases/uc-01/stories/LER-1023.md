## User Story
As a defence solicitor, I want compulsory boxes marked as compulsory, so that I do not discover an omission after the file has gone to the CPS.

## Acceptance Criteria
- Given a form with required fields, when it renders, then each required field is visibly marked as required.
  - Covered by: e2e/uc01-form-selection.spec.ts › `required fields are marked and contextual help expands`
- Given a required field I have touched and left empty, when it loses focus, then an inline message says it is required.
  - Covered by: e2e/uc01-form-selection.spec.ts › `inline validation message appears for an empty required field`
- Given a required date field, when I type an impossible date, then the message names the real problem rather than reporting the field as empty.
  - Covered by: e2e/uk-dates.spec.ts › `an impossible date is rejected at input`

## Notes & Constraints

- The required marker is Angular Material's own. The renderer must not add a second asterisk — it
  did once, producing "URN * *". Checkboxes sit outside `mat-form-field` and do add their own.
- Order matters in `errorMessage()`: `matDatepickerParse` is checked before `required`, because
  Material reports an unparseable date as an empty value and the required message would mask the cause.

- Template model: `libs/shared/src/lib/form-template.types.ts` and `form-templates.ts`.
- **Additive only:** a field id is permanent — `valuesJson` is keyed by id, so a rename strands live
  draft data on the next autosave (1.5s). `npm run orphan-scan` checks this.
- Every `data-testid` is load-bearing; MG1 is the fixture form for around 20 assertions.
- After changing `libs/shared`, restart the API — the nest watcher does not pick up shared-lib rebuilds.
