## User Story
As a defence solicitor, I want a case I cannot access to be refused clearly and my form kept, so that an access problem costs me an explanation rather than my work.

## Acceptance Criteria
- Given the case-link dialog, when it lists cases, then it shows only cases I may access and never a colleague-only case.
  - Covered by: e2e/uc01-form-selection.spec.ts › `dialog lists only accessible cases and never the colleague-only case`
- Given a request to start a form against a case I cannot access, when the draft is created, then it is created standalone and the response says the link was dropped.
  - Covered by: e2e/uc01-form-selection.spec.ts › `a draft requested against an inaccessible case is started standalone with a warning`
- Given such a draft, when the form opens, then a banner explains the link was dropped and that it can be linked later.
  - Covered by: e2e/uc01-form-selection.spec.ts › `a denied case link shows the explanatory banner on the form`
- Given a case I cannot access, when I request it directly by id, then the API answers 404 rather than confirming it exists.
  - Covered by: e2e/uc01-form-selection.spec.ts › `a case belonging only to a colleague is not readable`
- Given another user's draft, when I request it by id, then it is not readable.
  - Covered by: e2e/uc01-form-selection.spec.ts › `another user's draft is not readable`

## Notes & Constraints

- A denied link **degrades, it does not fail**: the alternative — refusing to create the form — would
  lose the user's intent over a permissions detail they may not control.
- 404 rather than 403 for an inaccessible case: a 403 confirms the case exists, which is itself a
  disclosure.

- Template model: `libs/shared/src/lib/form-template.types.ts` and `form-templates.ts`.
- **Additive only:** a field id is permanent — `valuesJson` is keyed by id, so a rename strands live
  draft data on the next autosave (1.5s). `npm run orphan-scan` checks this.
- Every `data-testid` is load-bearing; MG1 is the fixture form for around 20 assertions.
- After changing `libs/shared`, restart the API — the nest watcher does not pick up shared-lib rebuilds.
