## User Story
As a defence solicitor, I want spelling mistakes visible while I type the narrative, so that a statement does not go out with obvious errors in a witness's account.

## Acceptance Criteria
- Given the narrative text area, when it renders, then spell-check is enabled on it.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `a live word count tracks the narrative, and spell-check is on`

## Notes & Constraints

- Delivered as the browser's own `spellcheck="true"`, set explicitly on the textarea rather than left to
  the default. There is deliberately **no custom dictionary**: a legal-terminology dictionary is UC-06
  (Legal Language Assistance) territory, and a half-built one would flag correct legal usage as errors.

- The wizard is a **shell around** `DynamicForm`, never a fork: `apps/web/.../form-fill/mg11-wizard/`
  passes `visibleFieldIds` and the renderer still owns the single `FormGroup`.
- Shared, pure: `libs/shared/src/lib/mg11-declaration.ts`, `narrative-flags.ts`, `mg11-witness.ts`.
- MG11 carries **no `verification` marker**, which means "not yet assessed" — it is the quality bar but is
  **not** practitioner-verified. Do not mark it verified because it looks good (CLAUDE.md rule 2).
- **Additive only:** a field id is permanent; `valuesJson` is keyed by id.
