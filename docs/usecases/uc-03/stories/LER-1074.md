## User Story
As a defence solicitor, I want phrases that read as hearsay or opinion pointed out while I draft, so that the statement is corrected before it is served rather than in cross-examination.

## Acceptance Criteria
- Given a narrative containing the scope's phrases, when it is analysed, then every one is flagged with its kind and an explanation.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `flags every phrase the scope requires`
- Given the same phrases in different casing, when they are analysed, then they are still flagged.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `detects mixed-case variants`
- Given ordinary narrative prose, when it is analysed, then nothing is flagged — the detector does not cry wolf.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `does not flag ordinary narrative prose`
- Given a flagged phrase, when I hover it, then the explanation says what to write instead, not only what is wrong.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `hovering a flagged phrase explains why`

## Notes & Constraints

- **Five patterns, not three.** The DoD names *I was told that*, *I heard that*, *In my opinion*; the
  delivered list adds *I think* and *In my view*, both opinion, because the main flow says "hearsay or
  opinion" generally.
- Matching is word-boundary and case-insensitive, and internal whitespace matches any whitespace, so
  *"I  was told\nthat"* across a line break is still found. Overlapping matches resolve to the earlier,
  longer match, so "In my opinion" is never also reported as a nested shorter phrase.
- `detectNarrativeFlags` is pure and shared, so the browser and the API cannot disagree about what was
  flagged — which matters because the API's result is what reaches the audit trail.

- The wizard is a **shell around** `DynamicForm`, never a fork: `apps/web/.../form-fill/mg11-wizard/`
  passes `visibleFieldIds` and the renderer still owns the single `FormGroup`.
- Shared, pure: `libs/shared/src/lib/mg11-declaration.ts`, `narrative-flags.ts`, `mg11-witness.ts`.
- MG11 carries **no `verification` marker**, which means "not yet assessed" — it is the quality bar but is
  **not** practitioner-verified. Do not mark it verified because it looks good (CLAUDE.md rule 2).
- **Additive only:** a field id is permanent; `valuesJson` is keyed by id.
