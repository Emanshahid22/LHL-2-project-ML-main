## User Story
As a defence solicitor, I want MG11 to carry every box the real form carries, grouped as the form groups them, so that the statement I produce corresponds to the document that will be served.

## Acceptance Criteria
- Given the MG11 template, when it is loaded, then it declares fifteen fields across the sections Witness details, Statement, Declaration and Witness care, with eight required.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `step 1 holds witness details including the new title field`
- Given a case-linked MG11 draft, when it opens, then no witness field is auto-filled — a witness is not the defendant.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `UC-02 is unchanged: witness fields never auto-fill from the case`
- Given MG11, when the form opens, then the guided wizard is used rather than the flat renderer, and every other form keeps the flat renderer.
  - Covered by: e2e/uc03-mg11-wizard.spec.ts › `renders four steps, and only MG11 uses the wizard`
- Given every date field on MG11, when it renders, then it uses the shared datepicker with DD/MM/YYYY display and ISO storage.
  - Covered by: e2e/uk-dates.spec.ts › `every date field across all 11 forms uses the shared datepicker`

## Notes & Constraints

- `templateVersion` is **2**: version 2 added `title` and `specialMeasuresApplied`.
- No MG11 field carries `mapsTo`, and a check asserts it, so a future well-meaning mapping fails the suite
  rather than quietly naming the defendant on a witness statement.

- The wizard is a **shell around** `DynamicForm`, never a fork: `apps/web/.../form-fill/mg11-wizard/`
  passes `visibleFieldIds` and the renderer still owns the single `FormGroup`.
- Shared, pure: `libs/shared/src/lib/mg11-declaration.ts`, `narrative-flags.ts`, `mg11-witness.ts`.
- MG11 carries **no `verification` marker**, which means "not yet assessed" — it is the quality bar but is
  **not** practitioner-verified. Do not mark it verified because it looks good (CLAUDE.md rule 2).
- **Additive only:** a field id is permanent; `valuesJson` is keyed by id.
