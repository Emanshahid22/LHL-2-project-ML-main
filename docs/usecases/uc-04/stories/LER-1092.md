# LER-1092 — Dynamic threshold for summary matters

_UC-04 MG6 Unused Material Schedule · epic: `docs/usecases/uc-04/epic.md` · PRD: `docs/usecases/uc-04/prd.md`_

## User Story
As a defence solicitor handling a summary-only matter, I want a lower sparseness threshold, so that a short schedule on a simple case is not flagged as a problem.

## Acceptance Criteria
- Given a summary-only case, when the check evaluates, then a lower threshold applies than for a Complex case (the scope: "Lower threshold applied for summary-only matters").
- Given a summary-only case with an item count above its own threshold but below the Complex threshold, when the check evaluates, then it is NOT flagged — proving the threshold is genuinely per-band, not a single global number.
- Given the complexity bands, when they are defined, then each band has its own `minItems` in `COMPLEXITY_THRESHOLDS` and adding a band requires no change to the check's logic.
- Given a complexity value the system does not recognise, when the check evaluates, then it records `complexity: 'unknown'` and does not flag.
