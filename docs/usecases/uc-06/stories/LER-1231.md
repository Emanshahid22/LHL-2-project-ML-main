# LER-1231 — Nothing is ever auto-applied

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1231** (Story, To Do) · build order: story 09 of 15, stage 3._

## User Story
As a defence solicitor, I need certainty that nothing edits the statement but me, so that a witness's words are only ever the witness's words.

## Acceptance Criteria
- Given a narrative with prompts rendered in the panel, when time passes with no Insert pressed, then the control's value is byte-identical to what it was.
- Given the panel, when prompts appear, are dismissed, re-analysed and the field is blurred and refocused, then the narrative is still unchanged.
- Given the scope's Definition of Done line — "Suggestions are never auto-applied — verified by automated test that confirms text field is unchanged without a user Insert action" — when the suite runs, then a check asserts exactly that.
- Given the source, when it is inspected, then the narrative control is written in exactly one place: the Insert handler.

## Notes & Constraints

- This is the story the whole epic rests on, and it gets a structural check as well as a behavioural one:
  a source-level assertion that only the Insert handler writes the control, in the shape UC-02's
  case-write-path guard uses. A behavioural test proves today's build; the structural one protects the
  guarantee from the next refactor.

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
