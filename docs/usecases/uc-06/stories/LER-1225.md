# LER-1225 — The Legal Language Assistant panel

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1225** (Story, To Do) · build order: story 03 of 15, stage 2._

## User Story
As a defence solicitor, I want a panel beside the narrative I can open and close, so that help is there when I want it and out of the way when I do not.

## Acceptance Criteria
- Given a narrative field, when it takes focus, then a collapsible panel titled "Legal Language Assistant" appears beside it, carrying `data-testid="language-assistant"`.
- Given the panel, when I collapse it, then it stays collapsed for the rest of the session — a user who closed it meant it.
- Given prompts exist, when the panel renders, then each is a row showing its kind and its message, carrying `data-testid="assistance-prompt"`.
- Given no prompts, when the panel renders, then it states that the assistant only checks the patterns it has been given and is not a review of the statement.
- Given a non-narrative field takes focus, when it does, then no panel appears.

## Notes & Constraints

- The empty-state wording is not decoration. A narrative with no prompts is not a good statement; it is a
  statement the assistant has nothing to say about. This is the same honesty UC-05's consistency panel
  carries about unverified templates, and the panel is exactly where a user would over-read silence.
- `role="complementary"`, labelled, and it must never steal focus from the narrative — a panel that grabs
  focus mid-sentence is worse than no panel.

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
