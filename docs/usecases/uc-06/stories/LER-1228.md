# LER-1228 — Completeness hints

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1228** (Story, To Do) · build order: story 06 of 15, stage 2._

## User Story
As a defence solicitor, I want to be told what the account has not recorded, so that an omission is caught while the witness is still in front of me.

## Acceptance Criteria
- Given a narrative with no time recorded, when it is analysed, then the panel shows the scope's hint: "You have not recorded the time of the incident".
- Given that hint, when it ships, then its provenance is `documented`, cited to the scope document, because the scope states it verbatim.
- Given a narrative that does record a time, when it is analysed, then the hint does not appear.
- Given the sibling hints (date, place, who was present), when they ship, then they are `inference` and are observations only — they never offer wording to insert.
- Given an empty narrative, when it is analysed, then no completeness hints fire — an unstarted statement is not an incomplete one.

## Notes & Constraints

- The scope gives exactly ONE example. That one is grounded; anything else is our inference and must be
  labelled as such. Do not build a checklist of "required narrative content" — no source defines one, and a
  confident list of what a statement must contain is drafting doctrine we have no authority for.
- The empty-narrative rule matters: firing hints on a blank field would train users to ignore the panel,
  the same reasoning UC-04 applied to its sparse-schedule advisory.

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
