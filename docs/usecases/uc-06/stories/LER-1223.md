# LER-1223 — Declared narrative fields

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1223** (Story, To Do) · build order: story 01 of 15, stage 1._

## User Story
As a defence solicitor, I want the assistant to appear only on the boxes that hold prose, so that it never tries to correct the grammar of an address or a list of charges.

## Acceptance Criteria
- Given a template field that holds a witness's or officer's prose, when it is declared, then it carries `narrative: true` on its field definition.
- Given MG11, when the template is read, then `statementText` is declared a narrative and `witnessAddress` and `exhibitsReferenced` are not.
- Given MG5, when the template is read, then `summaryOfCircumstances`, `keyEvidence`, `defendantInterview` and `injuriesLoss` are declared narratives and `chargesList` is not.
- Given `narrative` on a field that is not a `textarea`, when `npm run conformance` runs, then it fails naming the field.
- Given the templates touched, when they ship, then `templateVersion` is bumped and no field id has changed — `npm run orphan-scan` reports zero orphans.

## Notes & Constraints

- The renderer must NOT infer prose from `type === 'textarea'` or from `rows`. MG11's
  `witnessAddress` and MG5's `chargesList` are textareas that are not narratives, and flagging "I think"
  inside an address is nonsense.
- Declaring it on the field keeps form codes out of the renderer, the same discipline UC-04 used for
  `group` and UC-05 for validation rules.

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
