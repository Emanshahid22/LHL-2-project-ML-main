# LER-1229 — Insert at cursor

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1229** (Story, To Do) · build order: story 07 of 15, stage 3._

## User Story
As a defence solicitor, I want a suggestion placed exactly where my cursor is, so that I can accept help mid-sentence and keep typing.

## Acceptance Criteria
- Given a prompt offering wording and a cursor in the narrative, when I press Insert, then the wording is spliced at the cursor position — not appended at the end.
- Given the insertion, when it completes, then the caret sits immediately after the inserted text so I can carry on typing.
- Given a selection in the narrative, when I press Insert, then the selection is replaced, as a text editor would.
- Given a narrative that has never been focused and so has no cursor, when the prompt renders, then its Insert is disabled rather than guessing a position.
- Given an insertion, when the draft autosaves, then the narrative persists through the existing save path with no new mechanism.

## Notes & Constraints

- Insert is the ONLY route from a prompt into the control. If a second path exists, the "never
  auto-applied" guarantee is only as strong as the next refactor.
- Splice at `selectionStart`; append-at-end would be the easy implementation and the wrong one — the scope
  says "at the cursor position".

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
