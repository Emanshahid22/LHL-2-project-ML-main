# LER-1226 — Informal-language flags with a formal alternative

_UC-06 Legal Language Assistance · epic: `docs/usecases/uc-06/epic.md` · PRD: `docs/usecases/uc-06/prd.md`_

_DevOps Bot ticket **LER-1226** (Story, To Do) · build order: story 04 of 15, stage 2._

## User Story
As a defence solicitor, I want informal wording pointed out with a formal alternative, so that a statement reads as a statement without me hunting for the right phrase.

## Acceptance Criteria
- Given the detector, when it ships, then `NarrativeFlagKind` includes `informal` alongside `hearsay` and `opinion`, and `NarrativePattern` carries an optional `suggestion`.
- Given a narrative containing an informal phrase, when it is analysed, then the phrase is marked with the amber highlight in the text AND listed in the panel.
- Given that panel entry, when it is displayed and the alternative can be attributed, then it offers the formal alternative to insert; when it cannot, it says only that the phrase reads informally.
- Given the amber mark and its panel entry, when either is examined, then they refer to the same range in the text.
- Given UC-03's five hearsay and opinion patterns, when the informal kind is added, then all five behave exactly as before.

## Notes & Constraints

- The highlight is free: reuse `segmentNarrative` and UC-03's backdrop, which already layers above a
  transparent textarea with `pointer-events: none` except on marks. Do not rebuild it.
- Informal register is observable from the text, so a FLAG needs no external authority — it is a statement
  about English. A proposed REPLACEMENT is drafting advice and does need one. That asymmetry is the story:
  flag freely, propose only what you can cite.

- Pure core: `libs/shared/src/lib/language-assistance.ts` (new) and UC-03's existing
  `narrative-flags.ts`. Panel: `apps/web/.../language-assistant/`. Narrative component:
  `apps/web/.../narrative-field/`.
- **Nothing is ever auto-applied.** The control's value may change ONLY inside the Insert handler. Any other
  write path is the defect this UC exists to prevent.
- **No invented phrasing.** A prompt may offer `insertText` only when its provenance is `documented` with a
  cited source — enforced by `canProposeVerbatim()` at runtime AND by `npm run conformance`, both.
- **Additive only:** never rename or delete a field id; bump `templateVersion` on any template whose fields
  change; run `npm run orphan-scan` around any id change.
- Reuse UC-03's detector and highlight backdrop; do not fork them. Its five hearsay/opinion patterns must
  behave identically afterwards.
- Amber is advisory; **red stays reserved for UC-07 sensitive material**. Design tokens only.
- After changing `libs/shared`, **restart the API** — the nest watcher does not pick up shared-lib rebuilds.
- Full mechanism and business rules: `docs/usecases/uc-06/prd.md` (§4 and §8).
