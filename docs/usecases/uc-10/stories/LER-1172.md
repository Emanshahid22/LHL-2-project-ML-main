# LER-1172 — Auto-attach to case documents

_UC-10 Form Archive & Case Attachment · epic: `docs/usecases/uc-10/epic.md` · PRD: `docs/usecases/uc-10/prd.md`_

_Client ticket **LER-1172** (Story, To Do) · delivering ticket: to be created after pack review · build order: story 3 of 16, stage 2._

## User Story
As a defence solicitor generating a PDF on a case-linked form, I want the document automatically filed under an "MG Forms" folder in the case's Documents section, so that no generated form is ever a loose download.

## Acceptance Criteria
- Given a case-linked draft, when generation succeeds, then the version attaches to that case (`caseId` on the version row) with `archiveStatus: 'attached'` and audit `DOCUMENT_ARCHIVED`.
- Given the case's Documents section, when listed, then the form appears under "MG Forms" grouped by lineage, current version as the primary entry (DoD line 4).
- Given a standalone draft, when generation succeeds, then no case attachment occurs (personal archive path — LER-1184).

## Notes & Constraints
- Attachment is a column in the mint transaction — the scope's independent-attachment-failure flow cannot occur; deviation recorded (PRD §10, open-questions #5).
- Internal case model only — external CMS blocked (open-questions #2).

## Definition of Done
- e2e: generate on the UC-10 fixture case → Documents section shows V1 Original; audit row present.
