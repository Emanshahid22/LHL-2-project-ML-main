# LER-1181 — Prior versions read-only

_UC-10 Form Archive & Case Attachment · epic: `docs/usecases/uc-10/epic.md` · PRD: `docs/usecases/uc-10/prd.md`_

_Client ticket **LER-1181** (Story, To Do) · delivering ticket: to be created after pack review · build order: story 8 of 16, stage 2._

## User Story
As the system of record, we want no version other than the current draft to be editable, so that history is immutable at the API, not the interface.

## Acceptance Criteria
- Given any superseded version's draft (FINALISED or ARCHIVED), when a save, autofill, review, finalise or reopen hits it, then 409 — every mutating endpoint refuses.
- Given a prior version in the drawer, when rendered, then the only action offered is download (LER-1180) — no edit affordance exists.
- Given DoD line 2 verbatim — "Prior versions are accessible for download but cannot be re-opened for editing" — when tested, then both halves hold in one e2e check.

## Notes & Constraints
- Overlaps LER-1175's lock; this story owns the SWEEP across all mutating endpoints.

## Definition of Done
- e2e sweeps every mutating endpoint against a superseded draft.
