## User Story
As a defence solicitor, I want every prior version downloadable from the drawer, so that any historical state of the form can be produced on demand.

## Acceptance Criteria
- Given any version entry, when its download is used, then THAT version's exact stored PDF serves through UC-09's verify-then-serve (tamper → 410, integrity audit) — bytes minted then, never re-rendered now.
- Given the filename, when derived, then it carries the version (`<formCode>-draft-<yyyymmdd>-v<N>.pdf`) and never case data (Global DoD #11; pii-scan covers it).
- Given a sensitive-bearing version, when downloaded, then the sensitive-retrieval story's re-check applies first.

## Notes & Constraints
- Downloads audit `DOCUMENT_DOWNLOADED` with `versionNumber` in metadata (no MG6D content in metadata ever).

## Definition of Done
- e2e: download V1 after 3 amendments; text-assert V1 content differs from V4's.
