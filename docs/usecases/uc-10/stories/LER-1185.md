_Client ticket **LER-1185** (Story, To Do) · delivering ticket: to be created after pack review · build order: story 10 of 16, stage 2._

## User Story
As a defence solicitor, I want to attach a standalone form to a case afterwards from the archive view, so that early drafting joins the case record when the case exists.

## Acceptance Criteria
- Given a standalone lineage, when `POST /archive/lineages/:id/link {caseId}` by its owner with access to the case, then the lineage's versions and drafts gain the `caseId`, `archiveStatus` becomes `'attached'`, audit `CASE_LINKED`; the case's Documents section now shows the full history (DoD line 3).
- Given a caller without case access or ownership, when linking, then 403.
- Given an already-linked lineage, when linked again, then 409 — un-linking does not exist; a mislink is corrected by a second audited link only if the first was to a wrong case — see PRD §4.

## Notes & Constraints
- The link dialog in the archive view is DoD line 3's home. Whole-lineage linking — versions never split across cases.

## Definition of Done
- e2e: standalone → link → Documents section shows all versions; 403/409 paths covered.
