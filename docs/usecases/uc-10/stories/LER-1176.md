## User Story
As a defence solicitor, I want an amended form to pass back through the UC-08 quality check before finalising and generating, so that no shortcut path produces a new version.

## Acceptance Criteria
- Given an amendment copy with a blocking finding, when finalise or generation is attempted, then 409 exactly as for any draft (`gateForGeneration` re-runs the engine server-side).
- Given a clean amendment, when finalised and generated, then the next version mints — the full UC-08 → UC-09 → UC-10 chain, no special-case code path.

## Notes & Constraints
- This story is a PROOF, not a feature: the mechanism already exists; the e2e pins that reopen didn't create a bypass.

## Definition of Done
