## User Story
As a defence solicitor reviewing an amendment, I want a field-level comparison between any two versions, so that exactly what changed — and when — is inspectable.

## Acceptance Criteria
- Given two versions of a lineage, when diffed, then each changed field shows its label, the from-value and the to-value; added and removed fields (template-version drift) show as such; unchanged fields are not listed.
- Given sensitive (MG6D) fields in the diff, when the caller lacks the permission, then values are redacted by the shared redaction — the diff never becomes a leak path.
- Given any two versions (not just adjacent), when selected in the drawer, then the same comparison runs — "any two" is the ticket's word.

## Notes & Constraints
- Diff runs on `valuesSnapshotJson` pairs — O(fields), no PDF parsing. Cross-template-version mapping per PRD §10.
- No scope sentence backs this ticket — the ticket is the requirement (open-questions #6).

## Definition of Done
- Unit tests on the diff algorithm incl. template-version drift; e2e: V1 vs V3 shows the exact edited field.
