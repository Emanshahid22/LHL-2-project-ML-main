# LER-1184 — Standalone form personal archive

## User Story
As a defence solicitor working on a form with no case yet, I want its generated versions stored in my personal MG Forms archive, so that standalone work is never orphaned outside the system.

## Acceptance Criteria
- Given a standalone draft (no `caseId`), when generation succeeds, then the version mints with `archiveStatus: 'personal'`, owner-scoped, visible in the archive view.
- Given the personal archive, when listed, then only the owner sees these lineages — no case-access path reaches them.
- Given the alt-flow text (scope: "form stored in the user's personal MG Forms archive"), when checked, then the whole version history lives there, not just the latest.

## Notes & Constraints
- Same storage, same encryption, same PII rules — "personal" is a scoping, not a different store.

## Definition of Done
- e2e: standalone generate → archive lists it; second user cannot see it.
