## User Story
As a defence solicitor, I want every version of a form preserved permanently, so that the case's paper trail is complete and no amendment erases history.

## Acceptance Criteria
- Given any number of amendment cycles, when history is listed, then every prior version row and its document remain present and downloadable — tested through 3 cycles (DoD line 1, verbatim target).
- Given any user action on the archive surface (link, reopen, regenerate, amend), when it completes, then no version row is deleted or mutated — the API exposes no delete/rename/renumber on versions at all.
- Given a direct attempt (crafted DELETE/PUT against version resources), when received, then 404/405 — the routes do not exist.

## Notes & Constraints
- Append-only is structural (no endpoint), not a permission check that could be misconfigured.
- Erasure/retention law questions are deliberately NOT solved here — open-questions.md #3 (human ruling).

## Definition of Done
- Schema + route-absence proven in e2e; 3-cycle preservation check green.
