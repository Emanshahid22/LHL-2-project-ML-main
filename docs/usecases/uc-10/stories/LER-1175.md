## User Story
As the system of record, we want the prior version locked the moment a copy exists, so that no path edits history.

## Acceptance Criteria
- Given a reopened form, when any edit hits the original draft, then 409 (already enforced for FINALISED; stays enforced).
- Given the amendment's first version minting, when it stores, then the superseded draft flips to `ARCHIVED` — locked against edit AND further reopen.
- Given the lock, when checked, then it is the API refusing — not a disabled button (client ticket's own words: "Enforced at the API").

## Notes & Constraints
- `ARCHIVED` is the schema comment's reserved status — UC-10 claims it; additive, no renames.

## Definition of Done
- e2e: edit-original 409; reopen-superseded 409; status transitions audited.
