## User Story
As a defence solicitor, I want a drawer listing every version of a form, so that the history is visible where the document lives.

## Acceptance Criteria
- Given a lineage with versions, when its row expands, then the drawer lists every version, newest first, current marked as primary.
- Given the drawer, when rendered, then prior versions offer download only; the current version offers download and (if FINALISED) reopen.
- Given a lineage of one, when expanded, then the drawer shows V1 "Original" alone — no empty-state confusion.

## Notes & Constraints
- Explicit scope requirement (flow step 5/6). Angular Material expansion — tokens only, amber advisories, red never (rule 6).

## Definition of Done
- e2e: drawer contents across 3 amendment cycles match the version rows.
