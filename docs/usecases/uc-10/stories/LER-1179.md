## User Story
As a defence solicitor auditing history, I want each drawer entry to show version number, generated date and generator, so that provenance reads at a glance.

## Acceptance Criteria
- Given a drawer entry, when rendered, then it shows `V<n>`, the label ("Original"/"Amendment N"), generated date (DD/MM/YYYY) and the generating user — alongside its download link (scope flow step 6, verbatim fields).
- Given the DTO, when fetched, then fields come typed from the API — no client derivation.

## Notes & Constraints
- Generator is the minting user's display name — already on the version row; no join to live user state that could drift.

## Definition of Done
- e2e asserts all four fields on V1 and V2 entries via data-testids.
