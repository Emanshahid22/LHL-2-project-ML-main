# LER-1163 — The DOCX draft label, on every page, verbatim

_UC-09 PDF Generation & Formatting · epic: `docs/usecases/uc-09/epic.md` · PRD: `docs/usecases/uc-09/prd.md`_

_Client ticket **LER-1163** (Story, To Do) · delivering ticket: **LER-2383** · build order: story 21 of 26, stage 3._

## User Story
As the guardian of "PDF is authoritative", we want every generated Word document to carry the scope's exact label in its header, so that an edited DOCX can never masquerade as the authoritative output.

## Acceptance Criteria
- Given any generated DOCX, when opened, then its page header carries the scope's exact wording — "Draft — not the authoritative version" — on every page (a running header, not a first-page banner).
- Given an unverified template, when its DOCX generates, then the draft-marking band's wording joins the header too — the DOCX is doubly a draft and says both things.
- Given the e2e suite, when it verifies, then it asserts the header at the OOXML level (header part XML), not by trusting generation code.

## Notes & Constraints
- This is UC-09's DoD 4, delivered whole; the wording is the scope's and is not paraphrased.

## Definition of Done
- Delivered against the criteria; OOXML-level check; full gate set green
