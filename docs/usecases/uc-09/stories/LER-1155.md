# LER-1155 — Eleven layouts declared as data behind the binding interface

_Client ticket **LER-1155** (Story, To Do — "Bind eleven HMCTS templates") · delivering ticket: **LER-2375** · build order: story 02 of 26, stage 1 (shared) · **re-scoped, deviation D2**._

## User Story
As the render pipeline's consumer, we want each form's page layout declared as data (`FormLayout`) behind a `LayoutBinding` interface with one clean-A4 implementation, so that layout is isolated from application code and a future overlay coordinate map is a second implementation rather than a rewrite.

## Acceptance Criteria
- Given `libs/shared`, when it builds, then it exports `FormLayout` data for all eleven forms, the `LayoutBinding` interface, and `CleanA4Binding` — and the binding is a pure function of (template, layout, values, case).
- Given the seven forms with genuine specimens (MG2, MG4, MG5, MG6, MG11, MG12, MG14), when their layouts are authored, then section order and grouping follow the specimen and each layout records its specimen source; the other four (MG1, MG3, MG15, MG16) record `structuralReference: none` and carry no fidelity claim.
- Given a template with fields the layout does not mention, when binding runs, then those fields still render (appended in template order) — a layout can arrange, never hide, declared fields.
- Given unit tests (`libs/shared/test`), when they run, then binding output is pinned for a fixture snapshot per form and the arrange-never-hide property is asserted.

## Notes & Constraints
- The original wording "bind eleven HMCTS templates" has no buildable referent: no official templates exist and HMCTS is the wrong authority (D2, `docs/answers/template-sourcing-evidence-2026-08.md`).
- AI-reconstructed specimens are never layout references (ground rule 1).
- Additive only: no template field ids change; `npm run orphan-scan` before and after.

## Definition of Done
- Delivered against the criteria; unit tests green in seconds (`npm run test:unit`)
- Both builds, conformance, orphan-scan green; API restarted and a template curl-asserted after the shared rebuild (HANDOVER §5)
