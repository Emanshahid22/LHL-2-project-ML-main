# LER-1161 — Exhibit reference hyperlinking, best-effort

_UC-09 PDF Generation & Formatting · epic: `docs/usecases/uc-09/epic.md` · PRD: `docs/usecases/uc-09/prd.md`_

_Client ticket **LER-1161** (Story, To Do) · delivering ticket: **LER-2381** · build order: story 19 of 26, stage 3._

## User Story
As a reader of a rendered MG11, we want exhibit references in the narrative linked to the exhibits section of the same document where the format allows, so that following "JS/1" is a click, not a page hunt.

## Acceptance Criteria
- Given a narrative containing references matching the established exhibit convention (the same `extractExhibitRefs` rules UC-08's crossRef uses — one module, not a second parser), when the PDF renders, then each becomes an internal link to the exhibit entry's anchor, and the link target exists.
- Given a reference with no matching entry in the document, when rendering, then it is left as plain text — a link to nowhere is worse than no link (the scope's "where the format allows", honoured literally).
- Given the PDF, when printed, then the links degrade silently — no visual noise on paper.

## Notes & Constraints
- Best-effort by scope wording; the crossRef advisory (UC-08) remains the place where a dangling reference is surfaced to the user.

## Definition of Done
- Delivered against the criteria; e2e asserts a linked and an unlinked case; full gate set green
