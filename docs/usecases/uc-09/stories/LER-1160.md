# LER-1160 — Preview scroll, zoom and download

_UC-09 PDF Generation & Formatting · epic: `docs/usecases/uc-09/epic.md` · PRD: `docs/usecases/uc-09/prd.md`_

_Client ticket **LER-1160** (Story, To Do) · delivering ticket: **LER-2380** · build order: story 18 of 26, stage 3._

## User Story
As a solicitor reviewing a multi-page document, we want scroll, zoom and a download button on the preview, so that checking a long statement does not require downloading it first.

## Acceptance Criteria
- Given a multi-page preview, when I scroll, then all pages are reachable; when I zoom (explicit controls, testid-carrying), then the document scales without clipping the page body.
- Given the download button, when clicked, then the file streams from the download endpoint with the LER-1167 filename — and a `DOCUMENT_DOWNLOADED` audit row records it.
- Given keyboard use, when the controls are focused, then they are operable with visible focus (the release block's accessibility pass should find nothing here).

## Notes & Constraints
- Zoom controls wrap the viewer rather than re-implementing it; no third-party viewer library.

## Definition of Done
- Delivered against the criteria; e2e covers scroll-to-last-page, zoom, download + audit row; full gate set green
